# 制作项目工作区调整计划

**目标：** 按本轮用户截图调整四步制作页，补充分镜字段，并让视频生成具备资产引用、模型参数、报价和片段预览的完整布局。

**实现方式：** 复用现有 Vue 页面、UI 组件、模型配置及生成/计费服务。保留第四步内镜头审片、批准、交付流程，成片管理改为入口弹窗。镜头新增角色、道具引用和音效字段，数据库迁移兼容旧数据。

**约束：** 在现有企业开发分支修改；保留之前工作树内容；新文件使用小驼峰；不新增测试文件或依赖；不提交收费生成任务。

- [ ] 顶部预算复用 `formatCredits`，四步改为清晰的连续步骤导航，状态与标题同行，指标上下居中。
- [ ] 移除成片面板常驻，只在第四步提供入口；剪辑台返回审片仍可直接打开成片管理。
- [ ] 独立分镜表展示镜头、时长、景别、角色、场景、道具、光影、音效、对白、旁白、机控、画面、状态、操作；编辑与数据库保存真实字段。
- [ ] 独立视频生成工作区采用左侧资产、中间提示词和模型参数、右侧预览、下方候选片段。引用资产显示缩略图，真实报价后允许提交。
- [ ] 运行前后端类型检查及构建；在实际页面验证四步切换、分镜编辑持久化、资产引用、报价、片段播放与成片入口，并保留截图。
