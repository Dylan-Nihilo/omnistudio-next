# 完整剧本实现计划

目标：第一步提供独立保存的全剧大纲、分集正文与版本记录，参照京东的目录和连续阅读布局。

约束：保留当前分支所有已有改动；不改 master；不新增依赖、数据库迁移和测试文件；所有新文件使用小驼峰。用类型检查、构建、实际接口及浏览器操作验收。

- [x] 复用 `productionScriptRecords.confirmedSnapshot` 保存 `scriptDocument`，首次确认保留原始输入；旧项目从已有分镜整理并标记来源。
- [x] 增加正文读取、保存和版本恢复接口，历史仅返回摘要。所有写入执行权限校验、项目锁定检查及 revision 冲突校验；恢复追加版本，保留生产结构及素材。
- [x] 新生成结果增加每集完整 `body`，在草稿预览中可编辑，确认时与分镜结构一起保存；兼容旧草稿未提供正文。
- [x] 新建 `productionScriptReader.vue`，提供大纲/分集目录、连续阅读、编辑保存、原稿查看、历史预览/恢复、文本导出与未保存离开保护；接入 `detail.vue`。
- [x] 执行路由生成、前后端类型检查和构建；浏览器验收正文编辑保存、刷新恢复、历史预览与恢复、目录折叠/分集定位、TXT 导出和已批准旧项目只读；打开结果预览。服务端实际接口验收了版本冲突 409、恢复追加版本及生产镜头不变。

正文版本是独立文档：保存和恢复不会重建镜头、视频或剪辑工程；进入视频生产后锁定正文写入，防止成片内容与剧本被无意改写。

## 项目内 AI 修订

本轮目标：补齐首页生成后，项目内继续使用 AI 修改大纲或单集正文的入口。复用现有模型目录、积分预估、收费文本流与版本保存，不自动重建分镜。

- [x] `ai/generate.ts` 显式区分首次生成与正文修订；校验项目权限、生产锁定和 expectedRevision，保持项目预算约束。服务端类型检查和构建通过。
- [x] `textGeneration.ts` 抽取文本流客户端；首页首次生成和项目内修订共同复用，缺失完成事件时不将部分输出当作完整结果。Web 类型检查和构建通过。
- [x] `productionScriptReader.vue` 提供范围、润色/改写/续写、模型、要求、自动预估、原文对照、生成中止、采纳草稿与新版本保存；保护未采纳结果及未保存修改。浏览器已确认选择模型和输入要求后自动报价，未点击付费生成。
- [x] 本轮前后端类型检查/构建与差异检查通过；实际 HTTP 验证过期版本、生产锁定与首次生成限制返回 409，缺少修订版本或项目返回 400。浏览器已打开 AI 面板，验证自动报价和必填要求控制并保存截图。未发起付费模型修订请求，因此尚未实测模型输出质量、真实扣费及完整的“预览-采纳-保存”操作链。
