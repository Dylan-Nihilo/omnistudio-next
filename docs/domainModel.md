# 用户与团队领域用语

**用户（User）**：独立的账户和创作者，拥有自己的个人空间与积分账户。团队成员关系不改变用户对个人资产的所有权。

**平台管理员（root）**：平台唯一的管理角色，负责平台 API、模型、积分与用户管理，具有跨用户和团队的管理权限。

**个人空间（Personal space）**：属于单个用户的项目、生成资产、会话、偏好与记忆的集合。生成资产默认保存在个人空间。

**项目（Project）**：个人空间中的创作工作目录，包含画布、文档、素材和 Agent 会话。

**团队（Team）**：用户主动创建或加入的协作组织，不拥有公共积分钱包，不自动收集成员的个人资产。

**团队所有者（owner）**：创建团队的用户，负责团队成员与团队资产管理；owner 是团队内的身份，不是平台管理角色。

**团队成员（member）**：加入团队的用户，可使用该团队授权的共享资产；其个人空间和积分仍独立。

**团队资产空间（Team asset space）**：团队成员主动上传共享副本的空间。上传不会移动或删除个人原件。

**积分账户（Wallet）**：属于单个用户的积分余额与冻结余额，团队关系不合并账户。

**积分划转（Transfer）**：当前同一团队的两个成员之间，从发送者个人可用余额到接收者个人账户的原子变动。
