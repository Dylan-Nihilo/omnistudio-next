# 用户体系交付报告

2026-10-09。本次实现使用项目已有的 Bun、Express、MySQL、Vue、Pinia 和自有 UI 组件，未增加依赖、测试文件或自动检查入口。

## 权限和产品行为

| 主体 | 权限与资产 | 积分 |
| --- | --- | --- |
| root | 唯一平台管理角色；访问所有页面，管理用户、API、模型、价格、扩展与团队资产 | 查看、发放和调整个人积分，所有管理操作记录审计 |
| 普通用户 | 个人项目、素材、会话、记忆与偏好独立；可以创建和加入多个团队 | 独立个人钱包，生成扣调用者自己的积分 |
| 团队 owner | 创建团队时自动取得；管理本团队成员、名称及共享资产 | 仍使用自己的钱包，无团队公共钱包 |
| 团队 member | 浏览、下载、主动上传共享副本；退出后失去团队访问权 | 只能与同团队当前成员划转个人可用积分 |

所有生成内容默认留在个人空间。上传团队执行复制，个人原件保留；没有后台收集。已上传副本在上传者离开后仍属于团队，owner/root 可以删除。归档团队保留数据，root 可管理和恢复。

## 本机使用

开发入口为 `http://127.0.0.1:5173`，后端 `127.0.0.1:3015`。独立 MySQL 为 Docker 容器 `omnistudio-next-mysql`，端口 `127.0.0.1:13306`，数据库 `omnistudioNext`。凭据保存在 Git 忽略、权限 0600 的根目录 `.env`。

正式数据库没有预置用户。首次打开页面初始化 root，原 5 个项目会登记为该账户的个人项目。之后普通用户自行注册。配置平台 API 凭据、启用模型并发布价格后才能使用对应生成能力。旧版共享服务入口需在账户中显式重新配置。

## 表单交互补充修复

用户反馈后发现原验收遗漏输入框留白的点击行为，且认证与团队表单仍使用浏览器默认校验。已修复自有 `uiInput` 的留白聚焦；将校验事件放在控件更新值之后，防止首次输入被重绘清除。注册、登录、初始化、团队创建与邀请复用现有 `uiForm/uiFormField`，错误提示关联到字段，不再显示浏览器默认校验弹窗。

独立验证库实际执行 root 和普通用户创建团队，接口返回 201，创建者成为 owner；实际执行注册、登录和邀请。另验证空值、邮箱格式、密码长度/确认、首次字符、中文组合输入事件链，以及常见桌面和 390×844 页面的一屏布局。此验证没有改动用户真实账号、团队或凭据。

后续慢点击复现确认另有弹窗焦点竞态：关闭按钮向输入框移动焦点时，`focusout` 回调在浏览器完成切换前看到短暂的 `BODY`，将焦点抢回 `DIALOG`。已在共享 `uiDialog` 中识别内部 `relatedTarget`，让浏览器完成切换；创建团队默认聚焦名称。鼠标按下停留 0/120/400/800ms 均能输入，Tab 保留在弹窗内、Esc 关闭及焦点恢复通过。

全局扫描 Web、自有 UI、节点与工具前端的图标/文字布局。首页“团队空间/平台管理”原先将图标放在文本插槽中，测得 4px 的基线偏移；现统一使用按钮图标入口。共享按钮的复合插槽、普通/边框单选项也改为居中排列，尾部箭头与长名称省略保留；原有正确的行布局和垂直说明布局不改。验证覆盖 85/100/125% 字体设置及长按钮标签。
