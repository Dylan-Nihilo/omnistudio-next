# 剪辑台混音基础实现计划

目标：在当前功能分支交付可实际制作的音频控制，优先改善对白与配乐混合。当前阶段包括轨道音量、独听、实时电平、片段音量关键帧和片段响度校准。

架构：复用现有工程 JSON、关键帧裁切、Web Audio 预览与 FFmpeg 后台导出。轨道 `volume` 默认 1、`solo` 默认 false；片段新增 `gainDb` 默认 0，音量关键帧取代片段静态音量，最终乘以片段增益、淡化和轨道音量。轨道静音优先，任意非文字轨独听后只保留独听轨声音。

约束：沿用 `codex/enterprise-comic-p0`，不改 master；不新增依赖、测试文件或自动检查入口；全部新命名小驼峰；通过内联命令、真实 HTTP、浏览器和 FFmpeg 验收。

- [x] 扩展工程校验、旧版本默认值和音量关键帧；分割、裁切、变速保持音量包络。
- [x] 导出与预览使用相同的轨道/片段音量语义，独听和静音可保存、撤销及恢复。
- [x] 音频页提供轨道推子、独听、静音与总输出电平；片段提供音量关键帧和增益。
- [x] 新增受鉴权和 CSRF 保护的片段响度分析接口，仅分析当前账户工作区；服务器生成固定 FFmpeg 参数，拒绝任意滤镜输入，支持超时和取消。
- [x] 响度校准分析选中源区间及恒定变速，按目标 LUFS 计算恒定增益，并以 -1 dBTP 真峰值和增益范围限制提升；静音无法测量时拒绝。校准不改原素材，结果应用后可撤销。
- [x] 实际验证权限、非法输入、源摘要不变、静音拒绝与取消；真实素材验证混音和校准，实际 HTTP 队列验证成片过载门禁。
- [x] Web/Server/FFmpeg 类型检查、Web/Server 构建与差异检查通过；已打开剪辑台音频页预览。

本阶段电平表为实时峰值 dBFS，不冒充 LUFS 表。片段校准采用测量后恒定增益，遇真峰值或最大增益限制会报告受限；不是动态压缩式的整片响度标准化。EQ、降噪、自动闪避和多声道后续另行实施，不在本阶段增加空入口。

## 实际验收记录（2026-11-09）

- Web 音频页：轨道推子、静音/独听、片段增益、音量关键帧和响度校准交互已操作；验收工程中的增益、关键帧和轨道变更均已撤销并保存，默认状态恢复。
- 预览移除了隐式压缩器，导出移除了隐式 `alimiter`；两端透明叠加轨道音量、片段增益、音量包络和淡化。总输出按左右声道分别取采样峰值，避免下混相位抵消；峰值保持到下一次播放或工程切换。浏览器实际播放时电平有响应，暂停后保留峰值（末轮为 -8.4 dBFS）。控制台日志只有刷新前的旧热更新错误，本轮无新增错误。
- 实际 HTTP 验证响度接口未登录 401、权限/CSRF 403、非法参数 400、无效媒体/静音/越界选区 422；有效 WAV 在 0.25～4 倍速下可测量；容器时长长于实际音轨的 MKV 选区被拒绝；取消可结束分析。源文件 SHA-256 前后相同。
- 真峰值受限样本：源 -34.53 LUFS / -0.09 dBTP，接口返回 `limited=true`、增益 -0.91 dB；对副本应用后复测 -35.43 LUFS / -1.00 dBTP，源文件不变。
- 持久渲染队列在发布前独立测量实际临时 MP4 的解码后真峰值，不信任前端滤镜统计标签；达到 0 dBTP、测量失败或取消均不发布。真实任务中，负峰值成功并复测 -16.91 dBTP，静音成功且 -inf；过载失败，公开提示“混音过载，请降低轨道/片段音量”，输出不存在且渲染临时目录清空。
- 历史 `alimiter` 工程仍可解析和运行，也接受同一成片门禁：低峰值通过；高峰值经 AAC 编码超调后被拒绝，需要降低片段/轨道音量再导出。限幅参数本身不代表成片安全。
- 已执行 `apps/server` 路由生成；`apps/web`、`apps/server`、`packages/ffmpeg` 类型检查，以及 Web/Server 构建与 `git diff --check`。Web 有现存的大 chunk 提示。未新增测试文件、测试脚本、框架或依赖。
- HTTP 验收的一次性账户、数据库任务行、临时媒体和工作目录已清理；现有用户工程与原素材保留。

边界：本轮完成混音基础，完整特效库、速度曲线、EQ/降噪/自动闪避和多声道不属于本阶段；本记录不替代干净目标机器上的安装、升级与长项目性能验收。成片真峰值测量会增加一次音频解码时间，失败任务需用户调整后重导出，不做隐藏音量修改。
