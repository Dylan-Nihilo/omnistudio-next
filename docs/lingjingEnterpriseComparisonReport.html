一、管理层结论

建议：把万象点点定位为“企业可控的漫剧生产操作系统”，优先补齐结构化剧集对象、资产连续性、任务队列、审片审批、成本中心和最小时间线；继续保留无限画布、供应商适配、自托管和开放扩展作为差异化。

灵境已经把“创意 → 分集剧本 → 主体资产 → 分镜脚本 → 视频生成”包装成明确的业务链路。本轮真实测试已完成剧本、主体资产和分镜脚本三个阶段，并用 Seedance 2.0 最低规格生成了第 1 集前 3 个片段；片段 04、05 提交后长时间无输出，整集成片仍未完成，不能把片段输出写成“视频交付已完成”。

万象点点的底座更适合企业深度集成：已有 Vue Flow 画布、媒体节点、3D 导演台、FFmpeg、SSE 进度、生成任务、积分账本、团队资产和审计基础。但当前业务对象仍偏画布和通用生成，缺少能支撑多企业订单的剧集、镜头、版本、审批、预算和交付闭环。

视频阶段的阻断证据

开启“合规素材自动审核”时，浏览器日志多次提示：使用素材库功能，请先同意 Seedance 2.0 模型使用承诺书。页面没有出现可点击的承诺书弹窗或签署入口；用户已在本次操作中明确授权继续测试，但这不能证明账号侧已完成第三方协议签署。关闭审核时，片段 01、02 曾进入队列并产出；片段 03 在审核开启后产出，片段 04、05 在审核开启后长时间挂起。企业正式生产必须把协议状态、素材授权和审核结果做成可审计的前置 Gate。
失败与挂起观察：片段 02 第一次提交曾等待约两分钟后无输出、余额保持 913，随后刷新并重新提交后成功；片段 04、05 各提交一次后连续等待超过 6 分钟仍无输出，页面只保留生成占位，没有失败原因、超时状态或任务历史。企业版必须提供心跳、超时、失败原因、重试次数、取消和人工接管状态，不能让“生成按钮恢复可用”成为唯一结果信号。

另观察到一次 Failed to fetch dynamically imported module 的动态模块加载错误，刷新后恢复。该事件需要进入稳定性指标，但不能据此推断整体可用性。

成员邀请与生命周期未执行邀请、接受、过期、撤销、重复邀请和错误邮箱测试；发送邀请会向第三方传输邀请信息。需第二身份及明确授权邀请状态可追踪，过期/撤销立即生效，移除成员后访问立即失效。
角色与越权未取得灵境租户的管理员、编辑者、审片者、只读者四类身份；不能从公开页面推断实际权限。未验证逐项验证创建、编辑、删除、生成、重拍、导出、邀请和预算操作；越权返回拒绝并留审计。
项目/资产共享C：我方已有团队共享资产上传独立副本、团队切换和移除成员后保留归档记录的实现；这不代表灵境具备同样行为。我方有底座，灵境待测项目可定向共享；资产版本、来源、授权和下载/复制权限可追踪。
审片协作本轮没有在灵境验证评论、@、批注、版本比较、审批、退回和锁定。未验证批准版本锁定；退回产生新版本；未批准版本不能标记为交付。
额度、预算与账单A：本轮只观察到个人余额变化和片段报价；未验证团队额度、项目预算、超额审批和成员/项目账单。未验证按组织/项目/集/镜头核算；失败、重拍和废片成本可区分；超额可阻断或审批。
并发与冲突没有第二个登录会话，未测试两人同时编辑、生成、删除或改名时的锁、冲突和状态广播。未验证并发编辑有锁或冲突提示；任务幂等；删除/改名不会造成另一会话静默覆盖。
审计与导出B：公开资料出现审计描述；本轮没有读取日志，也没有验证导出字段。待管理员实测覆盖登录、邀请、成员变更、资产授权、任务、成本、审批、导出和删除，包含操作者、时间、对象、结果。

最小可执行顺序

  1. 先用当前账号只读确认团队入口、当前角色、成员列表、资产页、用量/审计入口和项目共享入口，并截图或记录页面状态。
  2. 准备 owner/admin、editor/reviewer、viewer 三个测试身份；用无敏感测试剧集执行邀请、接受、角色矩阵、移除和资产访问回归。
  3. 在两个会话中同时编辑同一项目并提交同一镜头，记录冲突、重复扣费、状态刷新和任务幂等行为。
  4. 导出成员、权限、用量、账单和审计结果，与我方项目/镜头/任务/成本模型逐项映射。
授权边界：邀请外部测试账号、共享当前测试剧集、上传素材或导出租户数据都属于对外传输或权限变更；执行前需要指定测试账号和明确授权。没有这些前置条件时，报告只记录“待实测”，不填充推测结果。

八、POC 与采购前必须补测

  1. 用同一套 5 集短剧输入，分别完成角色/场景/道具、分镜和至少 1 个镜头视频，记录成功率、耗时、重试次数、单镜头成本和成片质量。
  2. 要求灵境厂商在测试租户提供可用的官方模型或明确完成 Seedance 承诺流程，由客户方自行确认合规条款；不得把“暂无可用模型”当作生产能力。
  3. 验证批量并发、失败重试、断点恢复、片段重拍是否保留旧版本、账单导出、团队预算、审计导出和 API 限流。
  4. 向厂商书面确认 SSO/OIDC/SAML、SCIM、数据驻留、私有化、备份、SLA、内容安全、版权归属和模型训练开关。
采购边界：在视频成片、企业身份、数据驻留和账单对账完成 D 级验证前，不建议仅凭公开入口承诺大规模订单交付。
