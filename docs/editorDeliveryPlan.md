# 剪辑台交付实现与验收计划

目标：在 codex/enterprise-comic-p0 功能分支补齐可用于制作交付的剪辑闭环，以实际素材、保存恢复和成片结果作为验收依据。用户已明确优先面向专业桌面剪辑，按 FilmCraft／剪映的编辑能力衡量差距。

架构：沿用 Vue、Bun、Express、现有工作区权限和 FFmpeg。页面负责交互与播放器，editorModel.ts 负责项目格式迁移和校验，editorExport.ts 负责确定性的导出。文件读写复用 workspaceFiles，不新增依赖或测试文件。

## 范围与依据

FilmCraft 的[公开说明](https://github.com/storytold/filmcraft/blob/main/README.md)包含多轨、专业修剪、双监视器、特效、关键帧、混音、后台导出任务与交换格式；它仍标记 alpha，自评实际制作就绪度约 56%，不能把其自评当作成熟度保证。RunningHub 指定项目当前需要登录，本轮不能核实受限功能。既有剪辑台只有固定三轨和基础修剪，尚不能称为等同上述产品的企业级成品。

本轮交付聚焦：大媒体流式导入和 Range 播放；视频/图片/音频/文字多轨；锁定、静音、隐藏和轨道顺序；源素材/成片双监视器、I/O 选区插入；逐帧波纹/滚动/滑移、波纹删除、恒定变速、画面变换、基础调色、透明度、淡入淡出和交叉淡化；SRT/VTT 与受限 CMX3600 EDL 导入导出；严格校验、备份恢复、素材重链接与冲突保护；可配置清晰度和质量的 MP4 导出、持久后台队列及取消清理。
