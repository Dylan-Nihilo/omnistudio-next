# 剪辑台交付实现与验收计划

目标：在 codex/enterprise-comic-p0 功能分支补齐可用于制作交付的剪辑闭环，以实际素材、保存恢复和成片结果作为验收依据。用户已明确优先面向专业桌面剪辑，按 FilmCraft／剪映的编辑能力衡量差距。

架构：沿用 Vue、Bun、Express、现有工作区权限和 FFmpeg。页面负责交互与播放器，editorModel.ts 负责项目格式迁移和校验，editorExport.ts 负责确定性的导出。文件读写复用 workspaceFiles，不新增依赖或测试文件。

## 范围与依据

FilmCraft 的[公开说明](https://github.com/storytold/filmcraft/blob/main/README.md)包含多轨、专业修剪、双监视器、特效、关键帧、混音、后台导出任务与交换格式；它仍标记 alpha，自评实际制作就绪度约 56%，不能把其自评当作成熟度保证。RunningHub 指定项目当前需要登录，本轮不能核实受限功能。既有剪辑台只有固定三轨和基础修剪，尚不能称为等同上述产品的企业级成品。

本轮交付聚焦：大媒体流式导入和 Range 播放；视频/图片/音频/文字多轨；锁定、静音、隐藏和轨道顺序；源素材/成片双监视器、I/O 选区插入；逐帧波纹/滚动/滑移、波纹删除、变速、画面变换、基础调色、透明度和淡入淡出；SRT/VTT 导入导出；严格校验、备份恢复、素材重链接与冲突保护；可配置清晰度和质量的 MP4 导出及取消清理。

- [x] 增加项目备份、恢复、草稿保护和素材重链接；遇损坏文件或外部修改时阻止静默覆盖。
- [x] 在 apps/web/src/pages/videoEditor/editorExport.ts 实现多轨合成、速度、音频混合、中文叠字、可配置 MP4 输出与输出校验；修复 FFmpeg 取消确认链路。
- [x] 为视频/图片的位置 X/Y 与透明度增加线性关键帧，覆盖编辑、预览、保存和导出；裁切、分割和变速同步重映射曲线。
- [x] 接入源素材/成片双监视器，支持 I/O 标记、选区播放、逐帧定位和播放头插入；跨点片段按源速度、关键帧拆分后同步顺移。
- [x] 接入波纹入出点、滚动右切点、滑移、波纹删除；同时提供帧数输入与拖拽模式，锁轨、源边界和 24 小时边界拒绝非法操作。
- [x] 预览与导出共用文字 Canvas 绘制；字体就绪后绘制，按字素换行，保留中文、emoji 与多行文本的一致布局。
- [x] 收紧远程 FFmpeg 参数/滤镜入口；宿主临时快照编码，排他发布成片，避免路径绕过和覆盖已有导出。

## 验收

- [x] Server 路由生成、类型检查、构建与鉴权 HTTP 实操；大于 100 MB 上传、Range、取消、不覆盖和路径越界检查。
- [x] Web 类型检查、生产构建、git diff --check。
- [x] 浏览器实际操作：旧项目迁移、导入图片/视频/音频、增删多轨、锁定/隐藏/静音、分割/撤销/重做、变速/调色/变换、字幕交换、保存重载与恢复。
- [x] 用真实素材导出多轨成片；FFprobe 核对分辨率、帧率、时长、音视频流；截帧检查画面和中文；验证静音、音频尾段、取消及失败清理。
- [x] 打开本地预览并保留验收证据；结果与未覆盖的边界记录到交付说明后提交当前分支。

## 已取得的验收证据

- Windows / Bun / Chromium，测试项目为 `editorSmoke`。浏览器成功导入 115,867,991 字节（110.5 MiB）H.264/AAC 视频、PNG、WAV 与中文字幕；工程重载后保留 4 个素材、5 条轨道、9 个片段。
- HTTP 实操覆盖 101 MiB 流式上传、Range 206、同名拒绝、取消清理、账户/CSRF 隔离，以及 SHA-256 版本冲突返回 409 且不覆盖较新文件。8 GiB 为实现上限，本轮没有传输完整 8 GiB 文件。
- 浏览器导出 `edited1794132324155596aabfb.mp4`：406 × 720、24 fps、10 秒、H.264/AAC；截图核对图片叠加及中文字幕。`edited1794132647871084f56b4.mp4`：1216 × 2160、24 fps、10 秒、H.264/AAC。竖屏输出按画幅等比计算偶数宽度，2160p 不代表固定 3840 × 2160。
- 本轮浏览器关键帧验收项目保存并重新载入后 X 曲线（-25% 到 25%）和透明度曲线（0.2 到 1）仍存在；时间中点读数分别为 0 和 0.6。新增中间点后执行撤销/重做，分别还原到 2 点和 3 点；另经受控 FFmpeg geq 输出 48 帧并逐帧取样，位置与 alpha 均按线性插值变化。
- 新受限远程协议在浏览器中实际导出 `edited17941354693908d41d34e.mp4`，FFprobe 确认 406 × 720、24 fps、10 秒、H.264/AAC；第 2 秒截帧确认变换叠加和中文字幕。高质量 `edited17941355713974c07aa2f.mp4` 确认为 1216 × 2160、24 fps、10 秒、H.264/AAC。
- 高质量重复导出实测取消后，浏览器显示“已取消导出，临时文件已清理。”工作区未出现新 MP4，宿主 `omnistudioFfmpeg*` 临时目录、脚本和渲染文件均已清理。预先同名输出碰撞内容保持不变；19 种参数/路径/滤镜/清单绕过在启动 FFmpeg 前拒绝。
- 80 段素材工程实际导出通过；滤镜图用脚本文件避免 Windows 命令行过长。超过命令行容量时返回可读错误。取消等待编码进程关闭后清理，不保留本轮未完成 MP4、PNG 或滤镜脚本。
- 保存队列的连续更新、跨目录保存隔离、CAS 冲突、恢复/忽略草稿前的快照核对均以内联调用验证；未新增任何测试文件。浏览器本地草稿按会话 UUID 分键，localStorage 本身不提供跨窗口事务。
- Web / Server 生产构建及 Web / Server / FFmpeg 类型检查已通过；Web 仍有既有大分包警告。
- 最终集成浏览器回归（24 fps）：波纹出点 +1 帧使跨轨后续片段同时顺移 1 帧；滚动 +1 帧保持工程总时长；滑移 +1 帧只改变源入出点。1–3 秒选区在 9 秒 13 帧插入后，由 10 个片段增加为 15 个，跨点的音视频/文字均拆分；撤销恢复到 10 个片段与 12 秒 1 帧。各操作均在浏览器界面执行，并恢复验收前工程。
- 最终集成成片为 `edited1794138957359884e62a1.mp4`：FFprobe 确认 406 × 720、24 fps、12.041667 秒、H.264/AAC；第 4 秒截帧确认图片叠加与两行中文字幕。
- 修复拖拽期间全局工程快捷键覆盖拖拽快照、片段外松手后点击抑制残留、普通修剪拖回时淡化丢失、空白文字标题导致保存失败。浏览器实操验证片段外松手后首次点击正常定位；原生输入空白文本后使用有效回退标题，正常保存并可撤销；并发拖动与撤销触发后，拖动结果保留且拖动结束后显式撤销可回到原时间点。浏览器自动化接口未暴露底层事件时间戳，未作为 OS 级高频输入压力验证。
- 素材源选区向下取整到完整帧，插入入口拒绝非整帧时长；插入点若落在既有片段的淡入/淡出内部，明确提示先调整淡化。内联调用确认淡入/淡出内部与 3.017 秒非整帧选择被拒绝，淡化端点允许；锁轨、源范围和 24 小时溢出均拒绝，输入工程不被修改。

## 交付边界

本轮功能闭环验收通过，但不能据此承诺达到剪映/FilmCraft 的完整专业桌面能力或企业认证。以下是正式专业桌面版交付前仍需独立实现或验收的工作：

- 代理媒体、缩略图/波形缓存与长素材性能：验证目标机器上的 4K 长素材、多轨播放、内存峰值、持续编辑响应和空间不足处理。
- 持久化批量渲染队列、任务恢复与崩溃故障演练：当前导出依赖前台会话；要验证进程中断、重启续管、磁盘写入失败和恢复结果。
- 转场/效果管理、速度曲线与关键帧曲线；当前仅提供基础调色、变换、线性 X/Y/透明度关键帧和片段淡化，不提供完整特效库。
- 专业音频：响度测量/归一化、轨道混音器、音频关键帧与更多声道；当前提供片段音量、变速、混音、轨道静音和限幅。
- 工程交换格式与格式矩阵：工程仍为内部 JSON，字幕支持 SRT/VTT；需独立验收真实相机/手机素材、可变帧率、旋转元数据、不同编码、OTIO/XML/EDL 等交换需求和目标操作系统。

当前范围面向单机项目制作。多人外部上线还需容量、并发、项目权限及进程级隔离门槛。FFmpeg 浏览器接口目前是受限的应用协议，不是操作系统级沙箱；本轮未运行完整 8 GiB 传输、多小时工程压力或桌面安装包跨平台验收。波纹编辑遇到跨切点重叠时会拒绝并提示整理轨道；跨淡化区间的插入会拒绝，避免改变既有包络。
