# 常见问题与故障排查

## 打不开或一直回到登录页

先确认访问的是团队部署或本机新版地址；重新走 `/auth/login`。若是首次启动，进入 `/auth/setup` 完成初始化。不要把旧版工作区地址当作新版入口。

## 首页创建项目提示目录不为空

“开始创作”要求空文件夹。已有 Toonflow 项目使用“导入项目”或首页项目卡片打开；不要清空含有素材的目录来绕过检查。

## 看不到画布或节点菜单

确认已打开工作区并选中“画布”面板；空白处双击打开节点菜单。若目标节点类型不存在，先到插件市场检查节点插件，再用画布实际返回的可用类型，不手写画布 JSON。

## 文档没有保存

等待顶部状态从“保存中…”变为“已保存”。保存失败时点击“保存失败，重试”，确认目录仍存在且有写权限。切换面板或退出前不要强行关闭窗口。

## Agent 说没有画布上下文

先打开目标工作区的目标画布，再打开 Agent。当前画布工具要求有活动画布；切换项目或画布后旧节点 ID、画布 ID 不能继续使用。

## Agent 找不到节点或引用编号不对

让 Agent 先 `getCanvas` / `findCanvasNodes`，再 `getCanvasNodes` 读取端口和 `getCanvasEdges` 读取入边。`{{ref N}}` 只按真实连接顺序编号；不要用节点名称、创建顺序或计划清单代替。

## 图片/视频生成按钮不可用

检查设置 → 媒体模型是否有可用供应商和模型；检查媒体生成插件对应类型是否允许；检查节点是否已选择模型和有效参考。生成前不要只看默认值，必须读取当前配置。

## 生成已提交但没有结果

“开始生成”只代表任务已提交。等待节点出现新的可读输出；不要重复点击。记录时间、节点、模型和返回状态。若失败，先读最新状态和原因，再决定是否在授权范围内重试。

## 生成结果人物漂移或伤势错误

只返修受影响的 P 节点：

- SH-08 后诺诺右肩伤、潜水灯应熄灭。
- SH-13 起路明非右手交易痕必须持续。
- P08–P10 只保持同一件主武器。
- 前半集只露诺顿局部龙眼/龙爪，不强行生成完整龙身。

保留旧采用版本，不因为一个片段的问题重跑全片。

## P07 不能设置 20 秒

以当前视频模型能力为准。将 P07 拆为 P07-A（SH-11–SH-12）和 P07-B（SH-13–SH-14），两段之间保持祭台、武器和人物状态；记录实际时长，不能在记录表中把两段伪装成一个 20 秒输出。

## 没有音频模型

先用音频节点导入团队 TTS 或外部录音。对白、音效和字幕仍按 `dialogueSoundList.txt`、`subtitleDraft.srt` 管理；没有实际音频就不要声称口型和字幕已验收。

## FFmpeg 未就绪

按插件市场页面安装/检测；仍不可用时先完成文本、图片、视频节点生产，并把合成与导出交给团队现有剪辑环境。

## 如何判断一集是否完成

必须分开记录：已生成片段、已采用片段、已合成成片、已归集文件。节点数量或 Agent 回复“完成”不能替代实际输出文件和人工/用户验收。

## 培训现场遇到未知菜单

拍下菜单名称和当前版本，记录为“现场确认”。不要根据旧版截图硬找入口；新版能力应以当前源码、节点 readme、实际插件和当前模型返回为准。
