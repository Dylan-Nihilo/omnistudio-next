# OmniStudio Next（Toonflow 新版）操作手册

本手册把《龙族·青铜城七宗罪》90 秒方案映射到新版“工作区 → 无限画布 → 节点 → Agent → 媒体输出”流程。旧版“项目剧本、资产中心、生产 Agent、分镜台、剪辑台”路径不作为本手册入口。

## 1. 先认识新版的工作方式

新版有两层“Workspace/工作区”概念：首次 `/auth/setup` 创建的是账号级平台 Workspace（管理员、邮箱、密码和 Workspace 名称）；登录后首页“开始创作”选择空文件夹创建的是本集的本地项目工作目录。今天做 EP01 时，先完成账号初始化，再创建 `dragonSevenSinsEp01` 本地项目目录。画布、Markdown 文档、图片、视频和音频都保存在本地项目目录中；首页项目列表只是入口记录，移除列表项不会删除目录里的文件。

一集内容建议拆成四层：

1. **依据层**：制作简报、完整制作稿、18 镜规划、连续性清单、对白清单。
2. **资产层**：角色、场景、道具和状态变体的图片节点。
3. **片段层**：P01–P10 视频生成节点；一个 P 片段可以包含多个 SH 内部镜头。
4. **声音与交付层**：音频节点、视频节点输出、外部或团队剪辑合成。

SH-01–SH-18 是内部镜头计划，不默认等于 18 次视频生成。P07 的计划时长为 20 秒，若现场视频模型不支持 20 秒，应拆为同状态的 P07-A / P07-B，并在记录表中登记。

## 3. 首页：创建或导入工作区

首页左侧主要入口：

- **开始创作**：输入创作描述，选择工作目录和文本模型后创建项目。
- **我的项目**：打开最近项目、导入已有工作目录、重命名或从列表移除项目。
- **账户与积分**：查看当前账号能力，以团队部署页面实际显示为准。
- **设置**：配置文本模型、媒体模型、插件和其他选项。

### 3.1 为本集新建工作区

1. 点击“开始创作”。
2. 在“选择工作目录”中选择一个**空文件夹**，建议名称：`dragonSevenSinsEp01`。
3. 在创作描述中粘贴：

   `建立《龙族·青铜城七宗罪》第一集工作区：9:16 竖屏、目标90秒、P01-P10十个片段、SH-01-SH-18十八个内部镜头、后期配音；先建立文本依据和连续性清单，不生成媒体。`

4. 选择已配置的文本模型，点击发送或创建项目。
5. 等待进入工作区。若已有工作区，使用“导入项目”选择其目录，不要在同一目录重复创建。

### 3.2 导入已有工作区

“导入项目”只建立入口记录并打开目录，不会自动解析旧版项目格式。若目录来自旧版 Toonflow，应先在文档面板确认文件，再按本手册重新建立节点结构。

## 4. 工作区界面

进入工作区后，顶部有：

- 项目名称和目录。
- **画布 / 文档**切换。
- **AI 对话**：打开或收起浮动 Agent。
- **设置**和**退出项目**。

退出工作区前，系统会尝试保存画布和文档；看到“项目未保存”时先留在项目重试，确认丢弃修改后才退出。

### 4.1 文档面板

文档面板左侧是“工作区文件”，支持新建 Markdown 文件、刷新文件树和打开 Markdown 文档。顶部会显示“保存中…”或“已保存”。

本集建议建立这些 Markdown 文件：

```text
00_制作简报.md
01_完整制作稿.md
02_18镜规划.md
03_资产与连续性.md
04_对白与声音.md
productionStateTemplate.md
```

画布中的文本节点适合做可引用的制作依据；文档面板适合保存较长正文、版本说明和记录表。两者不要互相覆盖成第二份不受控的正文。

### 4.2 画布面板

画布左上角的画布菜单可以：

- 切换画布。
- 新增画布。
- 编辑画布名称。
- 删除画布（至少保留一个；删除不可撤销，先确认范围）。

画布空白处双击打开节点菜单。当前仓库已确认的节点类型为；节点类型可见不等于团队部署已安装插件或已配置模型，培训现场仍需逐项检查：

| 节点 | 用途 |
| --- | --- |
| 文本节点 | 剧本、分镜、提示词、分析文本 |
| 图片节点 | 导入和固定角色、场景、道具参考图 |
| 图片生成节点 | 生成或修订图片资产 |
| 视频节点 | 导入、播放、截帧和保存视频素材 |
| 视频生成节点 | 文生视频、单图、首尾帧或混合参考 |
| 音频节点 | 导入和试听配音、音效 |
| 音频生成节点 | 以现场安装的节点插件和模型为准；本机核心仓库当前未提供独立 readme，培训前现场确认 |
| 3D 导演台 | 可选的动作、构图和运镜预演 |

节点之间只能连接真实兼容的输入输出。当前是空工作区时，先建立图片生成节点并完成基础资产生成、验收和登记，再把本轮已通过的输出连接到状态变体或视频节点；不要把文字描述当成图片参考，也不要根据节点名称猜端口或 `{{ref N}}` 编号。

画布控制区可按现场版本使用：素材库、网格吸附、边显示、视图适配、撤销/重做和选择操作。Agent 能调用 `getCanvas`、`addNode`、`connectNodes`、`getNodeTools`、`fitCanvas`、`arrangeCanvas` 等画布工具，但每次操作都应先读取实际节点和端口。

## 5. 设置：先把模型与插件配好

打开“设置”后按以下顺序核对：

### 5.1 文本模型

进入“文本模型”，添加团队允许使用的文本模型和服务凭证。Agent 对话、文本节点生成和导演台局部编辑会使用这里的配置。模型由平台统一配置，所有工作区共用可用模型。

### 5.2 媒体模型

进入“媒体模型”，分别确认图片、视频、音频模型。媒体供应商密钥不复用文本模型密钥。空工作区培训前必须确认：

- 一个图片模型：现场从零生成角色、场景和道具基础资产。
- 一个视频模型：基础资产验收后用于 P04、P06、P08 小样。
- 一个音频模型或团队 TTS 方案：用于对白试录；尚未接入时只导入外部音频，不把外部文件冒充为本轮已生成资产。

### 5.3 插件市场

在“插件市场 → 已安装”确认“画布操作”“工作区文件”“媒体生成”处于可用状态。媒体生成工具的图片、视频、音频开关控制 Agent 是否可直接调用对应生成；它不替代节点自身的模型配置。

工作区文件插件默认允许写入；演示只读时可打开其“只读模式”，但这样不能保存文档。培训正式实操前关闭只读模式。

### 5.4 FFmpeg

进入插件市场的 FFmpeg 项目检查状态。部分音视频处理、导出或供应商插件需要 FFmpeg；未就绪时按页面提示安装并重新检测。FFmpeg 就绪不代表 Toonflow 有固定的一键整集剪辑时间线。

### 5.5 MCP 与开发者选项

MCP 只在需要外部 Agent 操作 Toonflow 时开启。HTTP 配置包含访问凭证，只提供给可信客户端。开发者选项用于调试和手动安装插件，培训不把它作为普通创作者入口。

## 6. Agent 的正确用法

Agent 面板默认可见。输入框支持直接输入、粘贴图片/视频和使用 `@` 提及节点输出或工作区素材。发送前选择文本模型和推理级别；长对话可查看估算上下文用量。

Agent 能读取和操作当前画布、文档与已注册工具，但有三个边界：

1. 不能凭一句“做完一集”自动获得所有生成授权。
2. 图片、视频、音频生成会消耗模型额度，必须先展示对象、模型、规格、参考和数量，再明确批准。
3. 不能把完整剧本直接当作视频生成节点的专用提示词，也不能猜节点 ID、端口 ID 或引用序号。

推荐提示词都使用“只做当前阶段，完成后停止”的结尾。这样学员能看懂每一步，也便于发现错误。

## 7. 《七宗罪》完整生产流程

### 阶段 A：写入依据

1. 新建画布：`青铜城·七宗罪_EP01_90s`。
2. 建立文本节点：`00_制作简报`、`01_完整制作稿`、`02_18镜规划`、`03_资产与连续性`、`04_对白与声音`。
3. 把既有资料 `productionScript90s.txt`、`shotConfig18.txt`、`assetContinuity.md`、`dialogueSoundList.txt` 的内容写入对应节点或工作区 Markdown 文件。
4. 保存后回读，确认没有把镜号、时长和声音说明误写成需要朗读的对白。

### 阶段 B：准备资产

按 `assetContinuity.md` 和 `assetPrompts.txt` 从零建立图片生成节点，不导入或假设任何已有图片。生成顺序为：四个基础角色、八个基础场景、五个基础道具；基础资产逐项验收并登记实际输出文件后，再建立状态变体和固定主武器。

角色先生成设定表，再生成单人三分之二全身主图；视频首帧使用单人主图或清晰裁切。场景使用无人物主视图，道具使用同一物件的参考板。没有输出文件和验收记录的节点不能作为后续参考。

必须单独登记三个状态变体：

- `诺诺_右肩受伤_灯灭`：SH-08 后开始。
- `诺诺_受伤昏迷`：SH-17、SH-18。
- `路明非_右手交易痕`：SH-13 出现，SH-15–SH-18 保持。

### 阶段 C：先做三个小样

先建立 P04、P06、P08 三个视频生成节点：

- P04 / SH-06：验证龙眼局部、暗金竖瞳和水下青铜空间。
- P06 / SH-09–SH-10：验证受伤诺诺、路明非和路鸣泽的身份。
- P08 / SH-15–SH-16：验证交易痕、主武器、诺诺伤势和龙爪局部连续。

每个视频节点先用 `node:getConfig` 查看模型、模式、时长、分辨率、比例、音频开关和参考能力；再接入本轮已生成并验收的真实图片参考，读取实际引用顺序，写入一份完整片段提示词。生成前记录数量、费用和授权。若基础资产尚未生成或验收，只停在节点结构，不建立视频生成引用。

### 阶段 D：按 P01–P10 补齐

小样通过后按顺序建立和生成其余片段。每个 P 节点在提示词中合并对应 SH 镜头的动作、对白、音效和状态承接。节点返回“开始生成”不等于视频完成，必须等到节点出现新的可读输出，再记录文件和参数。

### 阶段 E：声音和合成

用 `dialogueSoundList.txt` 制作 14 句对白，固定每个角色的声音。无对白镜头不新增旁白。`subtitleDraft.srt` 只作占位，必须根据实际音频长度和最终裁切重排。

当前源码和节点说明确认了媒体节点、下载、播放和 3D 导演台导出能力；没有确认旧版“剪辑台一键完成整集”的固定入口。若团队扩展提供时间线，按 P01–P10 排序；否则在团队现有剪辑工具中合并视频、配音、音效和字幕，再回看最终 MP4。

## 8. 生成前、生成后检查

生成前必须确认：实际模型、模式、比例、分辨率、时长、音频开关、真实参考顺序、提示词版本、数量和费用。

生成后检查：人物身份、伤势方向、交易痕、武器是否始终同一件、空间承接、主动作数量、对白说话人、声音是否重复、画幅是否为 9:16、是否出现字幕或水印。发现问题时只返修点名的 P 节点或 SH 镜头，保留旧采用版本，不默认重跑全片。

## 9. 一句话记忆

**先把依据写进工作区，再把资产固定到画布；一个 P 片段一个视频节点，SH 只写进片段提示词；先小样、再授权、后批量；最终合成以现场真实能力为准。**
