# 培训流程

## 培训前 30 分钟准备

讲师逐项确认：

- 能打开团队部署或本机 `omnistudio-next`，能登录 `/auth/setup` 或 `/auth/login`。
- 空工作目录可选择，文件读写权限正常。
- 文本模型、图片模型、视频模型已配置；API Key 不在投影中展示。
- “画布操作”“工作区文件”“媒体生成”插件可用。
- FFmpeg 状态已检查；若未就绪，准备“导入外部音视频、外部剪辑”的备用路线。
- 准备本集资料：`productionScript90s.txt`、`shotConfig18.txt`、`assetContinuity.md`、`dialogueSoundList.txt`、`assetPrompts.txt`、`agentPrompts.txt`、`subtitleDraft.srt`。
- 不预置、不导入任何角色图、场景图或道具图；本次培训按空工作区从零建立图片生成节点。提前准备的是 assetPrompts.txt 和生成登记表，不是媒体文件。
- 投影中不显示 API Key、工作区隐私文件和未授权费用信息。

## 0–10 分钟：目标与新版心智模型

> 今天不从旧版“项目—分镜台—剪辑台”开始。新版的最小单位是工作区，核心是无限画布和节点。我们把《七宗罪》拆成依据、资产、片段、声音四层；P01–P10 是视频节点，SH-01–SH-18 是写进 P 节点的内部镜头。

屏幕动作：展示本资料包的 `workspaceChecklist.md`，指出三条硬约束：9:16、目标 90 秒、后期配音。

## 10–25 分钟：首页、登录和工作区

演示顺序：

1. 登录或初始化。
2. 首页“开始创作”。
3. 选择空文件夹 `dragonSevenSinsEp01`。
4. 输入“不生成媒体，只建立依据”的创作描述。
5. 进入工作区，展示项目名和目录。
6. 返回首页，再用“我的项目 → 打开项目”重新进入。

讲解重点：初始化时的 Workspace 名称属于账号级平台配置；今天再选择的 `dragonSevenSinsEp01` 才是 EP01 本地项目目录，画布和素材保存在这里；“从列表移除项目”不删除文件；旧项目导入不会自动变成新版节点结构。

学员动作：每人创建或打开自己的空工作区，并在群里报“已进入工作区”。

## 25–45 分钟：工作区、文档和画布

演示顺序：

1. 顶部切换“画布 / 文档”。
2. 文档面板新建 `00_制作简报.md`，输入一段制作简报，等待显示“已保存”。
3. 切回画布，空白处双击打开节点菜单。
4. 新建一个文本节点，命名 `01_完整制作稿`；再新建一个文本节点，命名 `02_18镜规划`。
5. 展示画布菜单的新建、切换和重命名画布。
6. 展示节点移动、连接、撤销/重做、视图适配和自动整理的用途。

讲解重点：文本节点是可引用的制作依据；Markdown 文档是工作区文件；连接要使用真实兼容端口，不能用显示名称猜端口。

学员动作：完成三个文本依据节点，写入本集的目标、P 表和连续性硬约束。

## 45–65 分钟：Agent 功能和分阶段指令

演示 Agent：

1. 打开右侧“AI 对话”。
2. 粘贴本资料包 `agentPrompts.txt` 的阶段 1 指令。
3. 展示 Agent 读取画布、报告结果和“完成后停止”。
4. 用 `@` 提及 `01_完整制作稿`，说明节点输出如何作为上下文。
5. 展示工具消息、上下文用量和停止生成按钮。

讲解三条边界：Agent 不自动获得媒体生成授权；不猜节点/端口/引用编号；失败或保存异常要先读取当前状态再决定是否重试。

学员动作：让 Agent 只输出资产清单和连续性清单，不创建媒体节点、不生成图片和视频。

## 65–90 分钟：图片资产节点

演示顺序：

1. 新建图片生成节点，说明图片模型、提示词、比例/分辨率；本轮基础资产使用无图片参考的文生图模式。
2. 按 assetPrompts.txt 先建立路明非、诺诺、一个核心大厅和七宗罪套组节点，展示节点清单和生成前配置。
3. 展示“生成前先确认模型、对象、参考和数量”的话术；未批准时不点击生成。
4. 获得批准后每个节点只生成一次，等待真实输出，逐项人工验收并登记文件路径；失败候选保留，不覆盖通过版本。
5. 基础资产验收通过后，建立状态资产名称：`诺诺_右肩受伤_灯灭`、`诺诺_受伤昏迷`、`路明非_右手交易痕`。

讲解资产验收：角色身份和服装、场景空间、道具形制、必要视角、伤势方向。空工作区不使用历史缩略图；只有本轮实际生成并登记的输出才能作为正式参考。

学员动作：至少完成一个基础角色、一个基础场景和一个基础道具的生成与登记；模型不可用时完成节点结构、提示词和“待生成”记录，不得填写虚构文件。

## 90–120 分钟：视频生成节点与三个小样

演示顺序：

1. 新建 `P04_龙眼显现`、`P06_救援与交易邀请`、`P08_反击与开路` 三个视频生成节点。
2. 为每个节点接入本轮已生成并验收的真实角色、场景和道具参考；没有通过资产时停在节点结构。
3. 读取节点当前配置：模型、模式、时长、分辨率、比例、音频开关。
4. 按 SH 顺序写入完整片段提示词。
5. 展示真实引用顺序和 `{{ref N}}` 只对应实际入边的规则。
6. 汇总生成数量、费用、风险，等待明确批准。
7. 获得授权后，演示每个节点只提交一次；生成中不重复点击。

讲师要明确：P06 的 SH-09 起诺诺已受伤；P08 的路明非右手有交易痕，诺诺右肩受伤且灯灭；P08 只使用同一件主武器，不同时挥舞七件。

学员动作：完成三个节点的提示词和生成前检查表；若模型或额度不可用，停在“待现场配置”，不要编造成功。

## 120–140 分钟：音频、字幕和交付边界

演示：

1. 导入一个音频节点试听配音或音效。
2. 说明音频节点可作为支持音频输入的视频节点参考；音频生成能力以现场插件和模型为准。
3. 打开 `dialogueSoundList.txt`，指出 14 句对白、无对白镜头和角色声音约束。
4. 打开 `subtitleDraft.srt`，说明时间必须以实际音频和最终裁切重排。
5. 说明新版当前确认的是节点媒体输出和下载/播放；整集时间线或一键合成需要团队扩展或外部剪辑。

学员动作：将一条对白或音效导入工作区，记录实际文件名和用途。

## 140–160 分钟：学员独立完成一个片段

学员从 P01、P03、P04、P06、P08 中任选一个，必须完成：

1. 一个命名正确的视频生成节点。
2. 至少一个本轮已生成并验收的真实图片参考连接。
3. 一份包含片段内 SH 镜头、动作、对白/无对白、音效、9:16 和无字幕约束的提示词。
4. 一份生成前模型与参数记录。
5. 不点击生成或只在现场授权的小组内生成一次。

讲师巡回检查：是否把整集剧本直接连到视频节点、是否猜了 `{{ref N}}`、是否忘记伤势/交易痕、是否误把计划时长当成模型保证。

## 160–180 分钟：故障排查、复盘和作业

复盘问题：

- 新版入口和旧版入口有什么不同？
- 为什么一个 P 片段可以包含多个 SH？
- 什么情况必须停在生成前核对？
- 画布保存失败或工作区切换时如何避免误写？
- 为什么 90 秒目标不能直接写成模型一定输出 90 秒？

课后作业：完成一个 P 节点的小样或生成前记录；将实际模型、参考文件、参数、费用和问题写入 `productionStateTemplate.md`。下一次培训先按记录验收，再决定是否批量生成。

## 讲师收尾话术

> 今天完成的是可复用的生产骨架，不是把所有生成按钮一次点完。先确认依据和连续性，再确认资产和真实引用，最后才批准媒体生成。任何“已完成”都必须有节点输出或文件证据；没有证据就记录为待核验。
