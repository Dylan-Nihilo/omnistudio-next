# OmniStudio Next 功能地图与菜单说明

状态标记：

- **源码确认**：已从 `omnistudio-next` 当前源码或节点 readme 看到入口/能力。
- **仓库文档确认**：仓库文档明确说明，但本次没有在团队部署中逐点击验证。
- **现场确认**：受部署、账号、插件、模型或扩展影响，培训开场必须确认。

## 首页与认证

| 功能 | 入口 | 状态 | 培训说法 |
| --- | --- | --- | --- |
| 初始化 | `/auth/setup` | 源码确认 | 首次安装按页面完成初始化 |
| 登录 | `/auth/login` | 源码确认 | 已有账号从登录页进入 |
| 开始创作 | 首页左侧 | 源码确认 | 选择空目录、输入创作描述、选择文本模型 |
| 导入项目 | 首页“我的项目” | 源码确认 | 选择已有工作区目录 |
| 重命名/移除列表项 | 项目卡片操作 | 源码确认 | 移除列表项不删除工作区文件 |

## 画布操作

| 功能 | 操作 | 状态 | 注意 |
| --- | --- | --- | --- |
| 新建画布 | 画布菜单“新增画布” | 源码确认 | 至少保留一个画布 |
| 切换/改名画布 | 画布菜单 | 源码确认 | 改名同步 `.json` 文件名 |
| 新增节点 | 空白处双击 → 节点菜单 | 源码确认 | 类型以当前安装节点为准 |
| 连接节点 | 拖动兼容端口 | 源码确认 | 先确认 source/target 和 dataType |
| 视图整理 | 画布控制或 Agent `arrangeCanvas` | 源码/技能确认 | 整理整个当前画布前先确认范围 |
| 视图适配 | 画布控制或 Agent `fitCanvas` | 源码/技能确认 | 只改变视口，不触发生成 |
| 素材库 | 画布控制区 | 现场确认 | 具体布局随版本和插件变化 |

## 节点能力

| 节点 | 核心功能 | 状态 | 《七宗罪》用法 |
| --- | --- | --- | --- |
| 文本 | 编辑/生成文本、输入输出 | 仓库文档确认 | 剧本、镜头、连续性 |
| 图片 | 上传/预览/替换/下载 | 仓库文档确认 | 固定正式参考资产 |
| 图片生成 | 文本/图片参考、比例、分辨率、停止 | 仓库文档确认 | 角色、场景、道具 |
| 视频 | 上传/播放/截帧/替换/下载 | 仓库文档确认 | 导入采用片段或取帧 |
| 视频生成 | 文生、单图、首尾帧、混合参考、音频选项 | 仓库文档确认 | P01–P10 |
| 音频 | 上传/试听/替换 | 仓库文档确认 | 对白、音效 |
| 音频生成 | 受插件和模型能力影响 | 现场确认 | 没有配置时导入外部音频 |
| 3D 导演台 | 动作、取景、关键帧、导出图片/视频节点 | 仓库文档确认 | 仅做复杂动作预演，可选 |

## 设置与插件

| 功能 | 入口 | 状态 | 明日培训动作 |
| --- | --- | --- | --- |
| 文本模型 | 设置 → 文本模型 | 源码确认 | 配置 Agent 和文本节点 |
| 媒体模型 | 设置 → 媒体模型 | 源码确认 | 配置图片/视频/音频供应商 |
| 插件市场 | 设置 → 插件市场 | 源码确认 | 检查工具开关和已安装插件 |
| 工作区文件只读 | 工作区文件插件配置 | 仓库文档确认 | 正式实操关闭只读 |
| 媒体生成开关 | 媒体生成插件配置 | 仓库文档确认 | 只在得到额度授权后打开/使用 |
| FFmpeg | 插件市场 → FFmpeg | 入口源码确认；状态现场确认 | 检查音视频处理依赖 |
| MCP | 设置 → MCP | 源码确认 | 仅外部 Agent 需要时开启 |
| 开发者选项 | 设置 → 开发者选项 | 源码确认 | 不作为普通创作入口 |

## Agent 已确认的工具类别

`canvas`、`workspace`、`mediaGeneration`、`askUser`、`skillOperator`、`webFetch`、`webSearch`。具体工具和权限以当前安装插件实时返回为准；看不到某工具时不要假定它已启用。

## 明确的交付边界

当前源码确认节点可以生成/导入/播放/下载媒体，3D 导演台可以导出图片或视频节点；具体插件是否安装、模型是否可用和导出是否成功必须现场确认。当前仓库文档没有确认固定的旧版一键整集剪辑台。最终合成、音频混音、字幕校时和发布按团队扩展或外部剪辑流程执行。
