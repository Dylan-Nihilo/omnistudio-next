## 从零生产原则

1. 先用纯文字生成基础角色、场景和道具节点；每个节点单独生成，不假设任何旧图片。
2. 基础资产生成后必须人工验收并登记实际输出文件，才能作为状态变体输入。
3. 状态变体只能从本轮已通过的基础主图生成：诺诺右肩伤/灯灭、诺诺受伤昏迷、路明非右手交易痕。
4. 七宗罪先生成套组，再从通过的套组中选一件固定主武器。P08–P10 只能使用这一件。
5. 纯文字不能证明视觉一致性已经达标。没有实际参考文件时，状态只能记为“待生成”或“待核验”。
6. 不猜 Toonflow 节点 ID、端口 ID、边顺序或 ref 编号。建立引用前先读取当前画布和节点配置。
