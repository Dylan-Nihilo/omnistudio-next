# 《龙族·青铜城七宗罪》工作区搭建清单
本清单按全新空工作区编写：当前没有任何可复用媒体，所有角色、场景、道具和状态变体都必须从零生成并登记。

## 1. 项目基本参数

```text
项目：龙族·青铜城七宗罪 EP01
画幅：9:16 竖屏
目标时长：90 秒（目标，不是模型保证）
制作方式：P01-P10 十个剧情片段；SH-01-SH-18 十八个内部镜头
声音：首轮视频按后期配音；字幕按最终音频和剪辑校时
平台：OmniStudio Next / Toonflow 工作区 + 无限画布
```

## 2. 推荐画布结构

画布名称：`青铜城·七宗罪_EP01_90s`

左侧放依据文本节点，中间放资产节点，右侧按时间从上到下放 P 视频节点。只在确有输入关系时连接媒体；不要用连线表示“阶段完成”或“需要批准”。

## 4. 资产清单

### 角色

- 路明非：先生成基础状态，SH-13起再生成右手交易痕变体。
- 诺诺：先生成基础状态，SH-08后生成右肩受伤/灯灭变体，SH-17/18使用受伤昏迷变体。
- 路鸣泽：基础黑西装状态，以倒影/幻象进入交易段。
- 诺顿：基础龙形态主图，视频前半集只裁取龙眼、龙爪或半身压迫影。

### 场景

- 黎明前三峡江面与支援船。
- 青铜激流通道。
- 青铜闸门区。
- 圆形核心机关大厅。
- 青铜祭台。
- 青铜机关大厅决战区。
- 向上水道。
- 支援船甲板。

### 道具

- 回程绳索。
- 青铜闸门和锁链。
- 七宗罪七件武器套组。
- 反击时使用的固定主武器。
- 潜水灯。
