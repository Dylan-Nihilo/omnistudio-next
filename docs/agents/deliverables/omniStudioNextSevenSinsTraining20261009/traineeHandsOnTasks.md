# 学员实操任务

项目：`《龙族·青铜城七宗罪》EP01`  画幅：9:16  目标：90 秒\
培训当天完成“骨架 + 一个片段”，不要求全员当天生成完整一集。

## 任务 1：创建工作区

- [ ] 登录或完成初始化。
- [ ] 选择空文件夹 `dragonSevenSinsEp01`。
- [ ] 进入工作区并确认顶部显示项目名和目录。
- [ ] 退出前看到文档/画布保存状态为“已保存”。

## 任务 2：建立依据

在画布中建立文本节点：

- [ ] `00_制作简报`
- [ ] `01_完整制作稿`
- [ ] `02_18镜规划`
- [ ] `03_资产与连续性`
- [ ] `04_对白与声音`

在文档面板建立：

- [ ] `00_制作简报.md`
- [ ] `productionStateTemplate.md`

依据内容必须包含：P01–P10、SH-01–SH-18、14 句对白、后期配音、无字幕生成、最终合成待现场确认。

## 任务 3：从零生成资产

工作区没有任何可复用图片。按 assetPrompts.txt 建立图片生成节点并从零生成：

- [ ] 路明非图片节点。
- [ ] 诺诺图片节点。
- [ ] 一个青铜城场景图片节点。
- [ ] 七宗罪套组或水下绳索道具节点。
- [ ] 记录模型、比例、分辨率、提示词版本和实际输出文件。
- [ ] 基础资产通过验收后，再建立状态变体节点。

连续性状态写入节点或 `03_资产与连续性`：

- [ ] SH-08 后诺诺右肩受伤，潜水灯熄灭。
- [ ] SH-13 起路明非右手出现交易痕。
- [ ] 反击时固定同一件主武器。
- [ ] 前半集只展示诺顿局部龙形态。

## 任务 4：建立一个片段视频节点

从以下选一个：

- P04：SH-06，龙眼苏醒。
- P06：SH-09–SH-10，救援与交易邀请。
- P08：SH-15–SH-16，反击与开路。

必须完成：

- [ ] 节点名称包含 P 编号和片段名称。
- [ ] 连接本轮已生成并验收的角色、场景、道具参考；没有通过资产时记录“待生成”，不填写虚构引用。
- [ ] 读取实际引用顺序，不猜 `{{ref N}}`。
- [ ] 提示词写明 SH 顺序、动作、对白或“无对白”、音效和状态。
- [ ] 写明 9:16、底部字幕区、不要生成字幕/文字/水印。
- [ ] 记录模型、模式、时长、分辨率、音频开关。
- [ ] 未获得授权前不生成；获得授权后一次只提交一次。

## 任务 5：声音记录

- [ ] 导入一条对白或音效到音频节点，或记录当前没有音频模型。
- [ ] 不给 SH-01、SH-06、SH-16、SH-18 添加新旁白。
- [ ] 字幕时间先记“待按实际音频校时”。

## 验收标准

讲师随机抽查一个学员的画布，能看到：

1. 依据节点与片段节点可区分。
2. 至少一条本轮已生成并验收的真实媒体引用连接。
3. 片段提示词没有把整集剧本当作唯一提示词。
4. 伤势、交易痕、武器和龙形态限制写清楚。
5. 生成状态和生成完成状态没有混写。
