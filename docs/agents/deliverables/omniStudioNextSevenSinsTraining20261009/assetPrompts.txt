青铜城·七宗罪｜从零生成资产提示词包

适用场景：新建的空工作区，没有角色图、场景图、道具图，也没有可以直接引用的历史资产。本文件不假设任何图片已经存在。每个资产必须在 Toonflow 中建立节点、生成候选、人工验收、保存版本后，才能作为后续状态变体或视频节点的参考。

## 使用规则

1. 先生成基础资产，再生成状态变体。基础资产未通过验收时，不继续生成变体或视频。
2. 基础资产使用无图片参考的文生图模式；如果模型强制要求参考图，换支持纯文本输入的模型，不填写不存在的 `{{ref N}}`。
3. 每个节点只负责一个资产。角色、场景、道具不要合并到一张大图中作为唯一资产。
4. 角色先生成设定表，再单独生成一张单人三分之二全身主图。视频首帧使用单人主图或清晰裁切，不直接把多视图设定表当首帧。
5. 记录节点名称、模型、比例、分辨率、提示词版本、候选文件、人工验收结果。候选、已通过主图和采用版本分别记录。
6. 变体提示词中的“输入参考”只表示下一阶段要连接的已通过节点；建立连接时读取平台实际节点和端口，不猜节点 ID、端口 ID 或 `{{ref N}}`。
7. 所有图片默认 9:16；孤立道具可用 1:1 或模型支持的接近比例，但进入视频前仍要准备 9:16 可读构图。

## 从零生成顺序和验收门

1. 先生成并验收四个基础角色、八个基础场景、五个基础道具。
2. 再从通过的基础主图生成三个状态变体：诺诺右肩受伤/灯灭、诺诺受伤昏迷、路明非右手交易痕。
3. 通过七宗罪套组后，生成并固定 `PROP_MAIN_WEAPON_固定主武器`；没有固定主武器前不建立 P08–P10。
4. 每个资产至少检查身份或形制、比例、画幅、文字水印、关键状态和文件路径。失败候选保留为候选，不覆盖已通过版本。
5. 只有资产有实际输出文件并登记后，才进入 P04、P06、P08 三个视频小样；没有输出文件时只能停在节点结构和生成前核对。
