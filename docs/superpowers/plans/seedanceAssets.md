# Seedance 素材库接入计划

**目标：** 工作空间素材库改用 Seedance 官方网关入库及审核，停用原个人文件素材库入口。

**架构：** 复用现有 `/api/assets` 和素材库界面。每个账户绑定独立的字节素材组，服务端保留上传源文件和画布导入缓存；远端素材 ID、审核状态及账户归属由服务端维护。生成时按文件内容匹配当前账户的已入库素材，使用 `asset://` 引用。旧 `assets` 目录不删除、不再作为素材库入口。

**技术栈：** Bun、TypeScript、Express、现有 conf 和工作区文件工具。

**依据：** 用户提供的《Seedance 对接文档 v2.1.html》第四章；文档仅作为接口资料。

## 约束

- 不新增依赖、测试文件或自动检查入口；复用现有供应商凭据读取。
- 网关统一 `POST /api/v3/asset?Action=...&Version=2024-01-01`，业务数据读取 `Result`，错误读取 `ResponseMetadata.Error`。
- 仅支持文档允许的图片、视频、音频；`Processing` 和 `Failed` 素材不能作为生成引用。
- 共享平台 Token 不能作为账户授权依据；所有素材 ID 必须核对个人登记记录。
- 原始文件通过有过期时间的签名地址供网关拉取，公网源地址必须能够访问此服务。

- [x] 修改 `apps/server/src/utils/conf/index.ts`：独立持久化素材组和登记记录，避免设置覆盖影响素材索引。

- [x] 生成路由，执行 server/web 类型检查和构建，手动验证官方接口、签名源地址、非法输入和账户隔离。
- 发布步骤：按此前已授权的流程提交、推送和部署，核验线上素材 API 连通。公网地址配置为 `https://studio.omnisline.com`。

## 验证结果

- 官方样例图片登记、状态查询达到 `Active`，素材库列表、内容匹配 `asset://`、重命名、删除均成功，临时素材组已清理。
- 签名源接口正常读取 HTTP 200，Range 请求 HTTP 206；无效签名和文件内容变化返回 HTTP 403。
- 非媒体、空文件、越界路径被拒绝；另一账户无法读取登记记录；匿名素材库请求返回 HTTP 401。
- server/web 类型检查和构建通过；未创建收费视频任务。
- 本地 `127.0.0.1` 回源被明确拒绝，避免登记必然下载失败的素材。本地文件入库需要单独配置指向本地服务的公网转发。
