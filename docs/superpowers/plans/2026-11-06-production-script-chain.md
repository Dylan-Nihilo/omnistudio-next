# 生产项目剧本创作链路实施记录

## 目标

把已保存于项目草稿的创作要求、主题材、融合题材、视觉风格、画幅和集数送入真实文本模型；生成结构化剧本草案，允许预览后一次性写入生产项目，随后继续使用现有资产、分镜和媒体生成阶段。

## 实施步骤

1. 扩展现有 AI 文本流：支持项目关联、受限输出 token 和项目预算预留；复用当前积分计费与模型配置。
2. 增加经过 Zod 校验的原子剧本写入接口，在单个事务内保存剧集、场景、镜头、角色/场景/道具资产及审计事件。
3. 将生产详情页的本地规则拆分替换为真实模型生成、可检查/编辑的草案预览和原子确认；题材与视觉风格提示分层传入。
4. 执行类型检查、构建和浏览器手动闭环；仅进行一次短文本生成实测，不调用媒体生成。

## 验收边界

- 生成任务复用用户积分结算、幂等键，并关联项目；项目预算与账户余额均不足时，不应调用上游模型。
- 用户确认前不写生产实体；确认后事务成功则全部写入，失败则不留下部分剧本结构。
- 实测核对模型、Token 用量、积分账本及重载后的项目内容。
- 不新增测试文件；附件解析、改编/转绘、图片/视频自动生成与最终成片不计入本次闭环。
