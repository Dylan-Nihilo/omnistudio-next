# 分镜 AI 工作流实施计划

**Goal:** 让生产分镜支持按集/全部待生成集 AI 生成，并支持编辑态单镜头 AI 分析填充。

**Architecture:** 服务端读取已确认剧本、当前集资产和镜头上下文，使用 `storyboardTeam` 的 writer/reviewer 生成整集草稿，并新增 `shotAnalyzer` 只返回单镜头字段补丁。批量生成逐集保存待审草稿；单镜头结果只回填浏览器内的表格编辑副本，最终仍由用户提交。

**Tech Stack:** Bun、TypeScript、Express、Drizzle、Zod、Vue 3、Pinia、现有团队与 Skill 运行器。

**Spec:** 京东灵境分镜工作区实测记录与本轮用户要求。

## 全局约束

- 保持当前 `codex/enterprise-comic-p0` 分支，不操作 master。
- 保留工作区已有未提交改动，不重置或覆盖无关内容。
- 不新增测试文件；执行类型检查、构建、路由生成和可行的手动链路验证并记录限制。
- 生成只创建待审草稿，单镜头结果不直接写入数据库。

### 阶段一：Agent 与服务端工作流

- 在 `storyboardTeam` 注册 `shotAnalyzer`，并扩展 storyboard Skill 的单镜头上下文、字段和资产约束。
- 增加剧集分镜状态、批量报价/生成、单镜头报价/分析接口；批量生成只处理没有正式场景且没有待审草稿的集。
- 报价按本轮实际目标集数汇总；生成逐集运行并返回逐集结果，部分失败不丢弃已完成草稿。
- 验证 `bun run routes`、server typecheck/build 与接口输入约束。

### 阶段二：生产工作区交互

- 显示每集待生成/待审阅/已确认状态，增加“全部生成”入口及进度/部分失败反馈。
- 在正式镜头表编辑态增加单镜头 AI 分析操作和文本模型选择；先报价并确认，再将模型结果只合并到空字段。
- 保持整集表格原有提交/取消语义，AI 分析失败或取消不得改动数据库内容。
- 验证 web typecheck/build，并手动检查按钮状态、单行回填、取消和批量结果状态。

### 阶段三：验收报告

- 记录每阶段命令输出、手动验证范围、未能实测项和残余风险。
- 不触发真实模型积分消耗作为验证手段。
