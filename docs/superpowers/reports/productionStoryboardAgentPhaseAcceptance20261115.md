# 阶段四分镜 Agent 垂直切片验收报告

**日期：** 2026-11-15<br>
**分支：** `codex/enterprise-comic-p0`<br>
**范围：** 现有生产项目的剧本版本 → storyboardTeam 待审分镜草稿 → 用户编辑/确认 → 原子写入场景和镜头。

## 当前结论

**基础接入与安全边界通过；全链路 Agent 生成验收暂不通过。**

本轮已完成持久化草稿、版本绑定、只读团队运行、生成前报价、草稿编辑/保存/过期检测、确认事务和生产页入口。真实模型生成会产生用户侧积分，本轮没有绕过界面确认直接调用模型，因此尚未取得模型真实输出、草稿刷新恢复和确认写入的端到端证据；不把类型检查和拒绝路径冒充为 Agent 生成通过。

## 已实现

- `productionStoryboardDrafts` 表和迁移保存项目、剧集、剧本 revision、草稿 revision、模型、`storyboardTeam` 版本、`storyboard` Skill SHA-256、草稿和确认状态。
- `storyboardTeam` 支持受控入口成员；本切片按 writer → reviewer 固定执行。团队工作目录是一次性临时目录，只提供 `read`/`ls`，并关闭团队资料写入。
- 两次文本调用都通过现有计费运行时，并关联 `projectId`、执行项目预算检查；报价覆盖 writer/reviewer 两次固定输出上限。
- 确认时不调用逐镜头接口，而是在一个数据库事务内重新锁定项目、核对剧本/草稿 revision、剧集归属、资产类型和适用集数，再一次写入场景、镜头和审计事件。
- 不启动图片、视频或音频生成；已有场景的剧集拒绝覆盖。

## 验收缺口与下一步

阶段四仍需一次用户确认的真实小样本验收：选择一个没有场景/镜头、已有确认剧本和资产的临时剧集，在面板确认报价后生成；编辑并保存草稿，刷新恢复；确认写入后检查场景、镜头、审计事件和 source revision；再用旧 revision、错误资产和重复确认验证 409 且无部分写入。完成这组证据后，才可把阶段四标记为通过并评估是否进入阶段五。
