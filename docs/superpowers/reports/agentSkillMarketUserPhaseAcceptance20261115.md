# 普通用户技能市场与个人安装阶段验收报告

**日期：** 2026-11-15<br>
**分支：** `codex/enterprise-comic-p0`<br>
**验收范围：** 普通用户市场入口、固定官方包目录、账户私有安装、账户级 Skill 加载、兼容预检、安装包完整性与权限边界。

## 结论

**阶段三 A 通过。** 普通用户可以在设置中发现官方精选 Skill、按用途搜索和按制作阶段筛选，查看来源、许可证、版本、安装能力要求、示例与限制，并安装到当前账户私有目录。目录包下载必须通过固定 SHA-256、包内 Skill 名称清单和当前 Skill 加载器预检。个人 Skill 与工作区/全局 Skill 分开显示；选择优先级为工作区、个人、全局。

浏览器验收使用当前登录账户完成了一次真实个人安装，六项 Skill 目前留在该账户的个人目录。验收未提交 Agent/模型请求，未执行包内脚本或媒体生成。

## 安全与范围

- 安装请求只接受目录中的固定 `packageId`；账户 ID 只从认证上下文取得。
- 账户技能路径位于 `data/users/<uuid>/skills`；加载与写入校验账户路径链的目录类型、符号链接和真实路径，账户目录权限为 0700，文件按 0600 写入。
- 目录固定上游 commit 与 SHA-256；解包后必须精确匹配目录中的 Skill 名称，随后由当前加载器在发布前预检。ZIP 内容只作为 Markdown 和资源文件保存，不运行包内脚本。
- AUTO 能加载并选择个人 Skill；Skill 不授予工具权限，生成仍遵循现有工具权限和确认流程。
- 浏览器验收安装的六项个人 Skill 保留在当前登录账户；这不是临时目录结果。其他安全与隔离演练使用的临时数据目录均已清理。
- 独立只读复核确认固定包摘要与复算结果一致，未发现阶段三 A 阻塞缺口。加载器预检只确认清单可解析并可加载，不验证上游脚本依赖或下游工具行为；市场详情已明确平台不执行这些脚本。

## 后续阶段

本阶段没有实现个人 Skill 的卸载、暂停 AUTO、升级差异、备份恢复或版本回滚。这些属于阶段三 B，需单独开发、运行实际验证并形成报告后再验收。
