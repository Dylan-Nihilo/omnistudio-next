# 分镜表格时长与长文本编辑验收报告

**日期：** 2026-11-17（北京时间）<br>
**分支：** `codex/enterprise-comic-p0`<br>
**范围：** 正式分镜表格时长编辑与长文本编辑器

## 行为调整

- 镜头时长是可修改字段，单位为秒；进入编辑态且镜头状态为 `draft` 或 `ready` 时显示数字输入框，并随表格“提交”保存。
- 时长列宽为 140px，为数字、步进按钮和点击区域留足空间。
- 不满足编辑条件的镜头只显示时长文本，不渲染输入框。集内存在已进入生成/审片状态的镜头或媒体候选时，隐藏整集编辑和添加入口，匹配服务端整集保存限制。
- 光影、音效、对白、旁白、镜头控制、画面描述改为点击内容打开大尺寸文本编辑器，支持全屏和字符计数。
- 弹窗“应用”只写入表格本地草稿；表格顶部“提交”才写入服务端。取消弹窗丢弃当前字段草稿，取消表格编辑丢弃本轮所有草稿。
