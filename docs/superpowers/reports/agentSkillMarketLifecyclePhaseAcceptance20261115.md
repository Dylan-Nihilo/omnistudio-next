# 个人 Skill 升级、回滚与卸载阶段验收报告

**日期：** 2026-11-15<br>
**分支：** `codex/enterprise-comic-p0`<br>
**验收范围：** 个人 Skill 包升级、备份、回滚、卸载与从备份恢复。

## 结论

**阶段三 B2b 通过。** 个人包生命周期在账户包级加单进程互斥；升级、卸载前先写入完整备份记录。卸载时将整批技能目录移入同文件系统的暂存目录，移动失败时按逆序恢复。备份恢复会校验账户备份清单、ZIP SHA-256 和目标目录快照；账户状态提交失败时，会按磁盘内容修复升级、回滚和恢复的版本记录，卸载备份则在删除目录前已持久登记。

## 实际验证

| 检查 | 结果 | 证据 |
| --- | --- | --- |
| Server 路由生成与类型检查 | 通过 | `apps/server` 执行 `bun run routes`、`bun run typecheck`，退出 0。 |
| Web 类型检查 | 通过 | `apps/web` 执行 `bun run typecheck`，退出 0。 |
| Server 与 Web 构建 | 通过 | 两端 `bun run build` 均退出 0；Web 构建保留既有大 chunk 提示。 |
| 升级前备份与并发互斥 | 通过 | 临时数据目录从真实固定目录包 v2.0.0 安装开始，同时发起两次 v2.1.0 升级；一个成功，另一个以 409 拒绝，记录与磁盘均为 v2.1.0。 |
| 回滚 | 通过 | 从升级生成的 v2.0.0 备份回滚，文件快照重新匹配固定 v2.0.0。 |
| 卸载与恢复 | 通过 | 卸载后账户状态标记为未安装，再从备份恢复并确认文件快照匹配 v2.0.0。 |
| 磁盘备份清单恢复能力 | 通过 | 在临时账户状态中移除备份 ID 后，仍通过磁盘备份清单定位备份并完成恢复。 |
| 篡改保护 | 通过 | 修改临时备份 ZIP 内容后恢复被拒绝，返回 409。 |
| 差异检查 | 通过 | `git diff --check` 无输出。 |

实际生命周期演练通过 `bun -e` 直接调用服务实现，在系统临时目录创建并清理独立数据目录；没有新增测试文件，也没有修改浏览器当前账户已安装的个人 Skill。独立只读复审未发现验收阻塞。

## 边界

文件锁使用现有进程内锁，适用于当前单进程 Server/桌面架构，不防止多个 Server 进程并发写同一账户。若文件系统同时拒绝安装/卸载及其逆向恢复，代码会保留暂存目录并报告路径；该极端故障仍需人工从暂存目录或持久备份恢复。
