# 剪辑台 AI 操作接入计划

**目标：** 在剪辑台的 AI 对话中，用受限工具操作当前工程的时间线。

**实现方式：** 复用现有 Agent `CanvasContext` 请求、工具 schema 校验和浏览器回传通道。剪辑台注册 `editor:` 命名空间，只允许读取工程摘要、添加现有素材、定位与分割片段，以及撤销最近一次 AI 修改。

**边界：** 不允许 AI 直接读写工程文件，不开放渲染、成片登记、画布回写、媒体导入、轨道删除或任意片段删除。每次修改都复用剪辑台现有函数、撤销历史与自动保存；上下文中的工程在用户切换或另行修改后拒绝后续工具调用。

**文件范围：** `packages/tools/canvas/src/runtime.ts` 定义严格参数 schema 和工具说明；`packages/tools/canvas/src/index.ts` 按 CanvasContext ID 将剪辑工具限制在剪辑台；`apps/web/src/pages/videoEditor/index.vue` 注册局部 CanvasContext、执行现有编辑函数并提供 AI 对话入口。

**验收：** 前端及工具包类型检查、构建；实际对话读取验收副本、添加一个现有素材、分割片段并通过 AI 撤销恢复。确认工作区画布对话不出现剪辑工具，切换工程后旧上下文调用被拒绝。遵守仓库规则，不新增测试文件。

## 实施与实测

- 已实现：剪辑台复用 floatingAgent 和 Agent `CanvasContext` 请求/回传；普通工作区只获得既有画布工具，`editor:` 上下文仅获得六个剪辑白名单工具。读操作返回素材、轨道、片段和播放头摘要，不返回磁盘路径。
- 已实现：工具参数采用严格 Zod schema；添加素材会核对素材、目标轨道类型及锁定状态；分割会核对片段、锁定状态和最小帧长。工具调用核对工程路径、页面代次和工程序列化快照，外部编辑会使旧调用失败。每个修改沿用剪辑台撤销栈和保存队列；AI 撤销只在操作前内容仍为撤销栈顶且当前内容仍等于该 AI 修改结果时生效。
- 已通过实际对话：AI 读取“布局改造验收副本”，报告 2 个视频素材、3 条轨道、2 个片段；将 `7d33f732-1851-47af-986a-5e66698c93f4.mp4` 添加到视频轨 15.5 秒处；再于 19.5 秒分割。`editorUndo` 成功撤销分割；人工再撤销 AI 添加，恢复原 2 个片段，保存状态显示“已保存”。
- 已通过隔离核对：工具包中工作区 context 返回原有 18 项画布操作，不包含任何 `editor*` 工具；`editor:` context 返回且仅返回 6 项剪辑工具。Zod 拒绝未知字段、路径字段及负数分割位置。
- 模型连接初次受当前命令网络限制；在提升权限启动本地服务后，实际 AI 工具调用成功。已配置模型的初次连接错误不是剪辑工具执行失败。
- 未实测：切换工程或用户并发修改时的 UI 端冲突场景；代码已在每次工具调用入口比较 context path/version 和完整工程快照并拒绝陈旧状态。完整生产验收仍应在有稳定模型连通的部署环境复验。
- 未开放：直接修改工程文件、删除/修剪片段、导出、登记、画布回写、媒体导入或轨道增删。
